# Karylite Official Website
Pool cleaning robot official site for Karylite, deploy on GitHub Pages.

## Structure
- index.html : main page
- assets/media : images & videos

## How to deploy
1. Upload all files to GitHub repository
2. Repository -> Settings -> Pages
3. Source: Deploy from a branch, select `main` branch, `/root` folder
4. Save, wait for build, you will get GitHub pages link.
